    A02.04 · Simulación de venta de entradas

    En la actividad anterior utilizamos estructuras condicionales para decidir si una inscripción podía realizarse. Ahora FestWeb necesita repetir determinadas operaciones para simular la venta de varias entradas.

    Durante esta actividad utilizaremos diferentes tipos de bucles para procesar ventas, controlar el aforo y generar listados de entradas.

    1. Objetivos

    Al finalizar la actividad serás capaz de:

    • Utilizar un bucle for cuando se conoce el número de repeticiones.
    • Utilizar un bucle while mientras se cumpla una condición.
    • Comprender la diferencia entre while y do...while.
    • Crear y actualizar variables contadoras y acumuladoras.
    • Evitar la creación de bucles infinitos.
    • Utilizar break y continue cuando sea necesario.
    • Seleccionar el tipo de bucle más adecuado para cada problema.
    • Comprobar el funcionamiento de un bucle mediante la consola.

    2. Punto de partida

    Trabajaremos con un evento de FestWeb que dispone de un aforo limitado.

    Dato Valor inicial
    Evento Festival Mediterránea
    Aforo total 10 personas
    Entradas vendidas inicialmente 4 entradas
    Precio por entrada 35 €
    Máximo de entradas por compra 4 entradas

    El programa deberá simular diferentes operaciones relacionadas con la venta de entradas.

    3. Preparación del proyecto

    1. Abre el proyecto de FestWeb.
    2. Localiza el archivo JavaScript principal.
    3. Añade un comentario para separar esta actividad:
    // A02.04 · Simulación de venta de entradas
    1. Declara los datos iniciales indicados en la tabla.

    4. Generación de entradas mediante for

    Utiliza un bucle for para mostrar los números de las entradas vendidas inicialmente.

    El resultado deberá ser:

    Entrada número 1
Entrada número 2
Entrada número 3
Entrada número 4

    Antes de programar, identifica las tres partes principales del bucle:

    Parte Finalidad
    Inicialización Establecer el valor inicial del contador.
    Condición Indicar hasta cuándo debe repetirse el bucle.
    Actualización Modificar el contador después de cada repetición.

    Puedes utilizar la siguiente estructura como punto de partida:

    for (/* inicialización */; /* condición */; /* actualización */) {
    // Mostrar el número de entrada.
}

    Antes de continuar

    ¿Qué ocurriría si el contador no se actualizara en cada repetición?

    5. Cálculo de la recaudación

    Utiliza un bucle for para simular la venta inicial de las cuatro entradas.

    En cada repetición:

    1. Muestra el número de la entrada.
    2. Añade el precio de la entrada a la recaudación total.
    3. Muestra la recaudación acumulada.

    El resultado esperado será:

    Entrada 1 vendida. Recaudación: 35 €
Entrada 2 vendida. Recaudación: 70 €
Entrada 3 vendida. Recaudación: 105 €
Entrada 4 vendida. Recaudación: 140 €

    Contador y acumulador

    Un contador suele aumentar en una cantidad fija, mientras que un acumulador guarda la suma progresiva de diferentes valores.

    6. Venta de entradas hasta completar el aforo

    Utiliza un bucle while para continuar vendiendo entradas mientras no se haya alcanzado el aforo total.

    En cada repetición:

    1. Incrementa el número de entradas vendidas.
    2. Calcula las entradas que quedan disponibles.
    3. Muestra el estado actualizado.

    El resultado deberá seguir esta estructura:

    Entrada vendida. Total: 5. Disponibles: 5
Entrada vendida. Total: 6. Disponibles: 4
Entrada vendida. Total: 7. Disponibles: 3
Entrada vendida. Total: 8. Disponibles: 2
Entrada vendida. Total: 9. Disponibles: 1
Entrada vendida. Total: 10. Disponibles: 0
Evento completo

    Utiliza la siguiente estructura como punto de partida:

    while (/* quedan entradas disponibles */) {
    // Registrar una nueva venta.
    // Actualizar los datos.
    // Mostrar el estado.
}

    Evita los bucles infinitos

    Alguna de las variables utilizadas en la condición debe cambiar dentro del bucle. Si la condición nunca deja de cumplirse, el programa continuará ejecutándose indefinidamente.

    7. Solicitud de una cantidad mediante do...while

    Utiliza prompt() para solicitar cuántas entradas desea comprar una persona.

    La cantidad deberá estar comprendida entre 1 y 4.

    Utiliza un bucle do...while para repetir la solicitud mientras el valor introducido no sea válido.

    do {
    // Solicitar la cantidad.
    // Convertir el valor a número.
} while (/* la cantidad no es válida */);

    El programa deberá aceptar únicamente estos valores:

    1, 2, 3 o 4

    Reflexiona

    ¿Por qué resulta adecuado utilizar do...while cuando necesitamos solicitar un dato al menos una vez?

    8. Validación de la compra

    Antes de registrar la compra, comprueba que:

    • La cantidad solicitada es un número.
    • La cantidad está entre 1 y 4.
    • Quedan suficientes entradas disponibles.

    Si la compra puede realizarse, muestra:

    Compra realizada correctamente.

    Si no quedan suficientes entradas, muestra:

    No quedan suficientes entradas disponibles.

    9. Uso de continue

    Simula la revisión de cinco solicitudes de compra numeradas del 1 al 5.

    La solicitud número 3 contiene datos incorrectos y no debe procesarse.

    Utiliza continue para omitirla y continuar con las solicitudes siguientes.

    El resultado deberá ser:

    Procesando solicitud 1
Procesando solicitud 2
Solicitud 3 omitida
Procesando solicitud 4
Procesando solicitud 5

    Uso de continue

    La instrucción continue interrumpe la repetición actual y hace que el bucle continúe con la siguiente.

    10. Uso de break

    Simula nuevas ventas mediante un bucle. Cuando se alcance el aforo total, utiliza break para finalizar el proceso.

    Después de salir del bucle, muestra:

    Proceso de venta finalizado: aforo completo.

    Uso de break

    La instrucción break finaliza inmediatamente el bucle en el que se encuentra.

    11. Resumen del evento

    Al finalizar la simulación, muestra un resumen mediante una plantilla literal:

    ----- RESUMEN DEL EVENTO -----
Evento: Festival Mediterránea
Aforo total: 10
Entradas vendidas: 10
Entradas disponibles: 0
Recaudación total: 350 €
Estado: Evento completo

    12. Elección del bucle adecuado

    Relaciona cada necesidad con el tipo de bucle que utilizarías principalmente:

    Necesidad Tipo de bucle
    Generar exactamente diez entradas numeradas.
    Vender entradas mientras quede aforo disponible.
    Solicitar una cantidad al menos una vez y repetir si es incorrecta.
    Recorrer una cantidad conocida de solicitudes.

    13. Casos de prueba

    Comprueba el programa con los siguientes datos:

    Caso Aforo Vendidas Solicitud Resultado esperado
    1 10 4 2 Compra aceptada
    2 10 8 3 No hay suficientes entradas
    3 10 10 1 Evento completo
    4 10 4 0 Cantidad no válida
    5 10 4 "abc" Cantidad no válida

    14. Ampliación subida a Aules

    Modifica la simulación para que el precio de las entradas cambie según el número vendido:

    Número de entrada Precio
    De la 1 a la 5 35 €
    De la 6 a la 8 40 €
    De la 9 a la 10 50 €

    Calcula la recaudación total teniendo en cuenta estos precios.
