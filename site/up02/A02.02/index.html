    A02.02 · Cálculo del precio de una entrada

    En la actividad anterior representamos los datos básicos de un evento de FestWeb mediante variables y constantes. Ahora utilizaremos esos datos para simular la compra de varias entradas.

    Durante la actividad aprenderemos a construir expresiones, utilizar operadores, convertir datos y comprobar el ámbito de las variables.

    1. Objetivos

    Al finalizar la actividad serás capaz de:

    • Utilizar operadores aritméticos, de comparación y lógicos.
    • Construir expresiones a partir de variables y constantes.
    • Identificar las conversiones automáticas realizadas por JavaScript.
    • Convertir explícitamente una cadena de texto en un número.
    • Comprobar el tipo de un valor mediante typeof.
    • Diferenciar entre == y ===.
    • Reconocer el ámbito de bloque de let y const.
    • Mostrar un resumen utilizando una plantilla literal.

    2. Punto de partida

    Trabajaremos con los siguientes datos:

    Dato Valor inicial
    Evento Festival Mediterránea
    Precio por entrada 35 €
    Entradas seleccionadas "2"
    Gastos de gestión 3 €
    Descuento 10 %
    Promoción activa Sí

    Importante

    El número de entradas se ha recibido como una cadena de texto. Antes de utilizarlo en determinados cálculos tendremos que comprobar y convertir su tipo.

    3. Preparación del proyecto

    1. Abre el proyecto base de FestWeb.
    2. Localiza el archivo JavaScript utilizado en la actividad anterior.
    3. Conserva los datos básicos del evento.
    4. Añade un comentario para separar la nueva actividad:
    // A02.02 · Cálculo del precio de una entrada

    4. Declaración de los datos

    Declara las variables y constantes necesarias para representar:

    • El nombre del evento.
    • El precio de una entrada.
    • El número de entradas seleccionadas.
    • Los gastos de gestión.
    • El porcentaje de descuento.
    • El estado de la promoción.

    Utiliza const para los valores que no deban cambiar y let únicamente cuando el valor pueda modificarse.

    Antes de continuar

    ¿Qué tipo de dato tiene inicialmente el número de entradas?

    Comprueba tu respuesta mediante typeof y muestra el resultado en la consola.

    5. Conversión del número de entradas

    Convierte el número de entradas a un valor numérico mediante Number() y guarda el resultado en una nueva constante.

    Después de realizar la conversión:

    1. Muestra el valor original.
    2. Muestra su tipo.
    3. Muestra el valor convertido.
    4. Muestra el tipo del valor convertido.

    El resultado esperado será similar al siguiente:

    Valor original: 2
Tipo original: string
Valor convertido: 2
Tipo convertido: number

    6. Cálculo del subtotal

    Calcula el subtotal de la compra multiplicando:

    • El precio de una entrada.
    • El número de entradas convertido a número.

    Muestra en la consola una frase con el siguiente formato:

    El subtotal de 2 entradas es 70 €

    Utiliza una plantilla literal para construir el mensaje.

    7. Comprobación de la promoción

    La promoción solo podrá aplicarse cuando se cumplan simultáneamente estas dos condiciones:

    • La promoción está activa.
    • Se compran dos o más entradas.

    Crea una expresión lógica que compruebe ambas condiciones y guarda el resultado en una constante.

    Muestra el resultado en la consola:

    ¿Puede aplicarse la promoción? true

    Reflexiona

    ¿Qué resultado se obtendría si la promoción estuviera desactivada? ¿Y si solamente se comprara una entrada?

    8. Cálculo del descuento y del precio final

    Si la promoción puede aplicarse, el descuento será el 10 % del subtotal. En caso contrario, el descuento será de 0 €.

    Calcula los siguientes valores:

    1. Importe del descuento.
    2. Subtotal después de aplicar el descuento.
    3. Precio final después de añadir los gastos de gestión.

    Redondea los resultados monetarios a dos decimales cuando sea necesario.

    El resultado esperado para los datos iniciales es:

    Subtotal: 70 €
Descuento: 7 €
Gastos de gestión: 3 €
Precio final: 66 €

    9. Igualdad débil y estricta

    Compara el valor original del número de entradas, que contiene "2", con el número 2.

    Realiza las siguientes comprobaciones:

    entradasSeleccionadas == 2
entradasSeleccionadas === 2

    Muestra ambos resultados en la consola y explica mediante un comentario por qué no producen el mismo resultado.

    Buena práctica

    Utilizaremos habitualmente la igualdad estricta (===) para evitar resultados inesperados provocados por conversiones automáticas.

    10. Ámbito de bloque

    Crea un bloque de código que represente la aplicación de la promoción:

    if (puedeAplicarsePromocion) {
    // Declara aquí una variable o constante local.
}

    Dentro del bloque:

    1. Declara una constante llamada mensajePromocion.
    2. Asígnale un mensaje que indique que se ha aplicado el descuento.
    3. Muestra el mensaje en la consola.

    Después, intenta mostrar mensajePromocion fuera del bloque.

    Observa el resultado

    ¿Puede utilizarse la constante fuera del bloque en el que ha sido declarada? ¿Qué mensaje muestra la consola?

    Corrige el programa eliminando o comentando la instrucción que provoca el error.

    11. Presentación del resumen

    Muestra en la consola una ficha completa de la compra utilizando una única plantilla literal.

    El resultado debe seguir esta estructura:

    ----- RESUMEN DE COMPRA -----
Evento: Festival Mediterránea
Precio por entrada: 35 €
Entradas: 2
Subtotal: 70 €
Descuento: 7 €
Gastos de gestión: 3 €
Total: 66 €
Promoción aplicada: true

    12. Ampliación entregable en Aules

    Modifica el programa para probar los siguientes casos:

    Caso Entradas Promoción
    Caso 1 1 Activa
    Caso 2 3 Desactivada
    Caso 3 4 Activa
    Caso 4 Valor no numérico Activa

    Para cada caso, comprueba:

    • Si puede aplicarse la promoción.
    • El descuento obtenido.
    • El precio final.
    • El tipo y la validez del número de entradas.

    Pregunta final

    ¿Por qué es importante convertir y validar los datos antes de utilizarlos en los cálculos de una aplicación?
