    Desarrollo Web en Entorno Cliente

    DWEC · 2.º DAW · Curso 2026/2027

    Del código que se ejecuta en el navegador a la creación de aplicaciones web completas con TypeScript y Vue.

    Bienvenida

    Cada vez que utilizamos una aplicación web, el navegador ejecuta código que permite mostrar información, responder a nuestras acciones, validar datos, comunicarse con servidores y actualizar la interfaz sin necesidad de recargar la página.

    En este módulo aprenderemos cómo funciona la programación web en el lado cliente y desarrollaremos aplicaciones cada vez más completas. Comenzaremos con los fundamentos de JavaScript, evolucionaremos progresivamente hacia TypeScript y terminaremos construyendo aplicaciones web mediante Vue 3.

    Pregunta de partida:

    ¿Qué ocurre realmente en el navegador desde que una persona accede a una página web hasta que interactúa con una aplicación completa?

    ¿Qué aprenderemos?

    A lo largo del curso aprenderemos a:

    • Comprender el funcionamiento de las aplicaciones web y la arquitectura cliente-servidor.
    • Programar con JavaScript utilizando variables, estructuras de control, funciones, colecciones y objetos.
    • Utilizar los objetos proporcionados por JavaScript y por el navegador.
    • Crear aplicaciones estructuradas y reutilizables mediante módulos y TypeScript.
    • Manipular dinámicamente el contenido de una página a través del DOM.
    • Gestionar eventos, formularios y mecanismos de validación.
    • Comunicarnos con servicios web mediante peticiones asíncronas y API REST.
    • Desarrollar aplicaciones SPA con Vue 3, TypeScript, Vue Router y Pinia.
    • Depurar, probar y documentar correctamente el código desarrollado.

    Nuestro recorrido tecnológico

    El aprendizaje seguirá una progresión gradual:

    1. JavaScript: fundamentos del lenguaje y del entorno del navegador.
    2. TypeScript: desarrollo de código más seguro, organizado y mantenible.
    3. Vue 3: construcción de aplicaciones web modernas basadas en componentes.

    Los contenidos trabajados en cada unidad se recuperarán en las siguientes, de manera que las actividades serán progresivamente más completas y estarán conectadas entre sí.

    ¿Cómo trabajaremos?

    Cada unidad combinará:

    1. Una explicación de los conceptos fundamentales.
    2. Ejemplos de código desarrollados y analizados en clase.
    3. Demostraciones prácticas mediante live coding.
    4. Actividades guiadas para aplicar los nuevos contenidos.
    5. Retos de programación y resolución de problemas.
    6. Desarrollo progresivo de aplicaciones web.
    7. Depuración, prueba y documentación del código.
    8. Validación de los aprendizajes y criterios de evaluación trabajados.

    La teoría no se planteará como un contenido aislado. Cada concepto se aplicará mediante código para comprender su utilidad, analizar su funcionamiento y utilizarlo posteriormente en proyectos más completos.

    Aprender a programar no consiste únicamente en escribir código, sino en comprender los problemas, diseñar soluciones y saber explicar las decisiones tomadas.
