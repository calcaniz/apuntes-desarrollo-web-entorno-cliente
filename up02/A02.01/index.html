    A02.01 · Datos de un evento de FestWeb

    1. Información de la actividad

    Proyecto de partida

    Descarga el proyecto base, descomprímelo y ábrelo con Visual Studio Code.

    Descargar A02.01 · FestWeb base

    Elemento Descripción
    Unidad UP02 · Fundamentos de JavaScript
    Duración 60 minutos
    Modalidad Actividad guiada mediante live coding
    Agrupamiento Trabajo individual con resolución conjunta
    Contenidos Primer programa, variables, constantes, tipos de datos, typeof, consola y plantillas literales
    Criterios relacionados CE02-a · CE02-b · CE02-h
    Carácter Formativo y no calificable

    2. Objetivo

    Crear el primer modelo de datos de un evento de FestWeb utilizando variables y constantes de JavaScript.

    Al finalizar la actividad deberás ser capaz de:

    • Crear y ejecutar un archivo JavaScript.
    • Declarar variables y constantes.
    • Elegir identificadores descriptivos.
    • Representar distintos tipos de datos.
    • Consultar el tipo de un valor mediante typeof.
    • Mostrar información utilizando la consola.
    • Construir mensajes mediante plantillas literales.
    • Interpretar los errores básicos de ejecución.

    3. Situación de partida

    FestWeb necesita almacenar la información básica de los eventos publicados en su plataforma.

    En esta primera versión todavía no utilizaremos objetos ni colecciones. Cada dato del evento se almacenará en una variable o constante independiente.

    Trabajaremos con el siguiente evento:

    Dato Valor
    Nombre Festival Mediterránea
    Categoría Música
    Localidad Tavernes de la Valldigna
    Precio de la entrada 35,50 €
    Aforo total 5000 personas
    Entradas vendidas 3200
    Inscripción abierta Sí
    Evento destacado Sí
    Requiere mayoría de edad No
    Fecha de cancelación No existe
    Patrocinador Todavía no se conoce

    Antes de programar

    Para cada dato, piensa:

    1. ¿Qué identificador utilizarías?
    2. ¿Qué tipo de valor representa?
    3. ¿Debe declararse mediante const o let?
    4. ¿Qué diferencia existe entre no conocer todavía un dato y saber que no existe?

    4. Preparación del proyecto

    Abre el proyecto de FestWeb con Visual Studio Code.

    Desde el terminal, instala las dependencias si fuera necesario:

    npm install

    Inicia el servidor de desarrollo:

    npm run dev

    Comprueba que el archivo index.html carga el archivo principal:

    <script type="module" src="/src/main.js"></script>

    Trabajaremos en:

    src/main.js

    Abre también las herramientas de desarrollo del navegador y sitúate en la pestaña Consola.

    5. Desarrollo de la actividad

    Parte 1. Primer dato del evento

    Sigue el live coding para representar el nombre del evento.

    Deberás observar:

    • Cómo se declara una constante.
    • Cómo se asigna una cadena de texto.
    • Cómo se muestra su valor.
    • Cómo se consulta su tipo.

    La consola deberá mostrar:

    Festival Mediterránea
string

    Parte 2. Información básica

    Declara los identificadores necesarios para almacenar:

    • El nombre.
    • La categoría.
    • La localidad.
    • El precio.
    • El aforo.
    • Las entradas vendidas.
    • Si la inscripción está abierta.
    • Si el evento es destacado.
    • Si requiere mayoría de edad.

    Utiliza:

    • string para los textos.
    • number para las cantidades.
    • boolean para las respuestas de sí o no.

    Elección entre const y let

    Utiliza const por defecto. Emplea let únicamente cuando el valor deba cambiar durante la ejecución.

    Parte 3. Ausencia de información

    Representa estas dos situaciones:

    • El evento no tiene fecha de cancelación.
    • Todavía no conocemos el patrocinador.

    Deberás utilizar valores diferentes para distinguir:

    • La ausencia intencionada de un dato.
    • Una variable que todavía no ha recibido ningún valor.

    Comprueba ambos valores mediante console.log() y typeof.

    Reflexión

    ¿Por qué no representa exactamente lo mismo utilizar null que utilizar undefined?

    Parte 4. Ficha del evento

    Muestra en la consola una ficha con el siguiente formato:

    ===== FESTWEB =====
Evento: Festival Mediterránea
Categoría: Música
Localidad: Tavernes de la Valldigna
Precio: 35.5 €
Aforo: 5000 personas
Entradas vendidas: 3200
Inscripción abierta: true
Evento destacado: true
Requiere mayoría de edad: false
Fecha de cancelación: null
Patrocinador: undefined

    Utiliza plantillas literales para insertar los valores dentro de los mensajes.

    Parte 5. Comprobación de tipos

    Muestra el tipo correspondiente a:

    • Nombre del evento.
    • Precio.
    • Aforo.
    • Inscripción abierta.
    • Fecha de cancelación.
    • Patrocinador.

    El resultado debe permitir observar las particularidades de null y undefined.

    6. Ampliación entregable en Aules

    Crea un segundo evento diferente.

    Debe incluir:

    • Tres cadenas de texto.
    • Dos números.
    • Tres valores booleanos.
    • Un valor null.
    • Una variable sin inicializar.

    Muestra una ficha completa y el tipo de cada dato.

    No copies únicamente el código anterior cambiando los valores. Revisa también los identificadores para que representen correctamente la información del nuevo evento.
