Las aplicaciones web forman parte de muchas de las actividades que realizamos diariamente. Consultar el correo electrónico, comprar una entrada, reservar alojamiento, ver una serie o inscribirse en una carrera son acciones que normalmente realizamos desde un navegador.

Aunque desde el punto de vista del usuario una aplicación web puede parecer un único producto, para que funcione deben colaborar diferentes elementos: el navegador, la conexión de red, el servidor, la aplicación que procesa las peticiones y, habitualmente, una base de datos.

En esta unidad estudiaremos cómo se organizan estos elementos y nos centraremos especialmente en el código que se ejecuta en el navegador. Este será el punto de partida para comprender el papel de JavaScript, TypeScript y, posteriormente, Vue en el desarrollo de FestWeb.
