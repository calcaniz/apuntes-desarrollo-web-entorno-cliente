# A02.03 · Decisiones en la inscripción de FestWeb

En las actividades anteriores hemos almacenado los datos de un evento y calculado el precio de una compra. Ahora necesitamos que **FestWeb tome decisiones** en función de los datos de la inscripción.

El programa comprobará si quedan entradas, si la persona cumple la edad mínima y qué mensaje debe mostrar según el número de entradas disponibles.

## 1. Objetivos

Al finalizar la actividad serás capaz de:

- Crear estructuras condicionales con `if`, `else if` y `else`.
- Combinar condiciones mediante operadores lógicos.
- Seleccionar entre diferentes opciones mediante `switch`.
- Utilizar el operador ternario para decisiones sencillas.
- Ordenar correctamente las condiciones de un programa.
- Probar distintos casos y comprobar el resultado obtenido.

## 2. Punto de partida

Trabajaremos con los siguientes datos iniciales:

| Dato { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Valor inicial { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| **Evento** { .table-text-bold .table-cl-secundario } | Festival Mediterránea |
| **Edad de la persona** { .table-text-bold .table-cl-secundario } | 20 años |
| **Edad mínima** { .table-text-bold .table-cl-secundario } | 18 años |
| **Entradas disponibles** { .table-text-bold .table-cl-secundario } | 15 |
| **Tipo de entrada** { .table-text-bold .table-cl-secundario } | `"general"` |
| **Precio base** { .table-text-bold .table-cl-secundario } | 35 € |

El programa deberá decidir:

1. Si la inscripción puede realizarse.
2. Qué mensaje debe mostrarse según la disponibilidad.
3. Qué suplemento corresponde al tipo de entrada.
4. Cuál es el precio final.
5. Qué estado debe mostrar la inscripción.

## 3. Preparación del proyecto

1. Abre el proyecto de **FestWeb**.
2. Localiza el archivo JavaScript principal.
3. Añade un comentario para separar esta actividad:

```js
// A02.03 · Decisiones en la inscripción de FestWeb
```

4. Declara los datos iniciales indicados en la tabla.

## 4. Comprobación de la disponibilidad

Utiliza una estructura `if...else` para comprobar si quedan entradas disponibles.

El programa deberá mostrar uno de estos mensajes:

```text
Hay entradas disponibles.
```

```text
El evento está completo.
```

!!! pregunta "Antes de programar"

    ¿Qué expresión puede utilizarse para comprobar que el número de entradas disponibles es mayor que cero?

## 5. Comprobación de la edad

La inscripción solamente podrá realizarse cuando se cumplan simultáneamente estas dos condiciones:

- Quedan entradas disponibles.
- La persona tiene la edad mínima requerida.

Construye una condición que combine ambas comprobaciones mediante el operador lógico adecuado.

El programa deberá mostrar uno de estos resultados:

```text
La inscripción puede realizarse.
```

```text
La inscripción no puede realizarse.
```

!!! pregunta "Reflexiona"

    ¿Qué operador lógico debemos utilizar cuando es obligatorio que se cumplan las dos condiciones?

## 6. Mensajes específicos de rechazo

Amplía la estructura anterior para que el programa explique por qué no puede realizarse la inscripción.

Deberán contemplarse los siguientes casos:

| Situación { .table-full-container .table-content .table-bg-principal .table-cl-secundario } | Mensaje { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| No quedan entradas. | El evento está completo. |
| La persona no alcanza la edad mínima. | No cumples la edad mínima requerida. |
| Se cumplen ambas condiciones. | La inscripción puede realizarse. |

Utiliza una estructura formada por `if`, `else if` y `else`.

!!! warning "Orden de las condiciones"

    El orden de las comprobaciones es importante. El programa debe mostrar un único mensaje y explicar correctamente la situación detectada.

## 7. Estado de disponibilidad

FestWeb mostrará un mensaje diferente según el número de entradas disponibles:

| Entradas disponibles { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Estado { .table-full-container .table-content .table-bg-principal .table-cl-secundario } |
|---|---|
| 0 | Evento completo |
| Entre 1 y 5 | Últimas entradas |
| Entre 6 y 20 | Disponibilidad limitada |
| Más de 20 | Entradas disponibles |

Utiliza una estructura condicional encadenada para obtener y mostrar el estado correspondiente.

Con los datos iniciales, el resultado debe ser:

```text
Disponibilidad limitada
```

!!! pregunta "Piensa antes de escribir"

    ¿Por qué conviene comprobar primero si el número de entradas es igual a cero?

## 8. Tipo de entrada

El evento ofrece tres tipos de entrada:

| Tipo { .table-main-column .table-content .table-bg-principal .table-cl-secundario } | Suplemento { .table-content .table-bg-principal .table-cl-secundario } |
|---|---:|
| **General** { .table-text-bold .table-cl-secundario } | 0 € |
| **Preferente** { .table-text-bold .table-cl-secundario } | 15 € |
| **VIP** { .table-text-bold .table-cl-secundario } | 40 € |

Utiliza una estructura `switch` para asignar el suplemento correspondiente.

La estructura deberá incluir también un caso `default` para detectar un tipo de entrada no reconocido.

!!! warning "Recuerda"

    Añade `break` al final de cada caso para evitar que el programa continúe ejecutando los casos siguientes.

## 9. Cálculo del precio final

Calcula el precio final sumando:

- El precio base de la entrada.
- El suplemento correspondiente.

Muestra el resultado utilizando una plantilla literal:

```text
Tipo de entrada: general
Precio final: 35 €
```

Si el tipo de entrada no es válido, el programa deberá mostrar un mensaje de error en lugar de calcular el precio.

## 10. Estado mediante un operador ternario

Utiliza un operador ternario para guardar en una constante uno de estos dos valores:

- `"Aceptada"` si la inscripción puede realizarse.
- `"Rechazada"` si la inscripción no puede realizarse.

Muestra el resultado en la consola:

```text
Estado de la inscripción: Aceptada
```

!!! pregunta "Reflexiona"

    ¿Sería adecuado utilizar un operador ternario para toda la lógica de esta actividad? Justifica brevemente tu respuesta.

## 11. Presentación del resultado

Muestra un resumen final de la inscripción mediante una plantilla literal.

El resultado para los datos iniciales debe seguir esta estructura:

```text
----- INSCRIPCIÓN FESTWEB -----
Evento: Festival Mediterránea
Edad: 20 años
Edad mínima: 18 años
Disponibilidad: Disponibilidad limitada
Tipo de entrada: general
Precio final: 35 €
Estado: Aceptada
```

Esta entrada:

- Aplicará un descuento de 5 € sobre el precio base.

Prueba la nueva entrada con una persona de 22 años y otra de 30 años.
